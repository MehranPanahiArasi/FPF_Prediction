FPF Prediction from SEM Images

This repository provides the complete implementation of a two-stage hybrid framework for predicting the Fine Particle Fraction (FPF) from scanning electron microscope (SEM) images of inhalation powders. The pipeline first classifies images into four FPF intervals using a fine-tuned DenseNet169 model, then applies class-specific Random Forest regression to estimate the exact FPF value. The repository includes three core scripts: FPF_Prediction.py for model training and evaluation, interpretability.py for generating Grad-CAM heatmaps to interpret model predictions, and Data_Analysis.py for statistical validation of the dataset. The Data folder contains all SEM images and corresponding FPF labels. This work demonstrates a cost-effective and rapid alternative to conventional in vitro methods for formulation screening and quality control. Please see the accompanying paper for a full description of the methodology and results.
